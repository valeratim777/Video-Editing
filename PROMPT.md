Это мой репозиторий для монтажа вертикальных риллс. Перед началом прочитай `CLAUDE.md`, навык `.claude/skills/reels/SKILL.md` (особенно §4 «Studio voice» и §5 «Build») и `projects/testimonio/NOTES.md` — там всё, что уже сделано и решено в прошлой сессии.

## Задача
Доделать риллс «Testimonio» и выдать финальное видео с **по-настоящему студийным звуком**.

- Исходник: `projects/testimonio/assets/source.mp4` — 6:20, вертикальное 720×1280, снято на телефон в зале церкви. Парень у кафедры даёт свидетельство **на испанском**, девушка рядом переводит на английский. В риллс идёт **только испанская речь парня**.
- Монтаж уже готов и согласован: `projects/testimonio/edit.json` — 14 фрагментов, ~63 с, тексты субтитров выверены вручную. **Не меняй** выбор фрагментов, тексты и визуальный стиль без моего согласия.

## Что сделать
1. **Окружение (Linux).** ffmpeg, Node, Python 3.11, `npx hyperframes@latest` (+ `hyperframes models install parakeet` для распознавания; на Linux можно и whisper). Шрифты, звуки и библиотека эффектов уже лежат в навыке.
2. **Звук — главное.** Сейчас звук «очень плохой»: телефонный микрофон + эхо зала. Простое шумоподавление (DeepFilterNet) и эквалайзер не помогают — нужна генеративная реставрация речи.
   - Собери «сырой» звук по монтажному листу: `scripts/cut-audio.mjs`.
   - Восстанови его через **Resemble Enhance** (режим enhance, lambd 0.9, tau 0.5; на CPU — кусками по 8 с, на GPU — как есть). Можешь попробовать и другие сильные модели, если они реально лучше.
   - Лёгкий мастеринг (без тяжёлого эквалайзера), −14 LUFS, true peak < −1 dBTP.
   - Докажи качество цифрами: **DNSMOS OVRL ≥ 2.7** и выше, чем у исходника (сейчас: исходник 1.32, DeepFilterNet 2.13, Resemble 2.73 на отрывке). Сравни 2–3 варианта и выбери лучший. Сохрани 15-секундные образцы «до/после» в `projects/testimonio/out/samples/`, чтобы я сравнил на слух.
3. **Видео.** `build-base.mjs` → `align.mjs` (проверь соотношение «якорей» у каждого фрагмента) → `captions.mjs` → `gen-html.mjs` → `hyperframes check` → снимки кадров. Убедись, что **нет тишины > 0,5 с** ни на стыках, ни внутри фрагментов (`tighten.mjs`, `split-pauses.mjs`), а субтитры совпадают со словами.
4. **Рендер** `--quality delivery`, затем замени звуковую дорожку на отреставрированную (рендер HyperFrames меняет громкость). Сделай копию для телефона < 30 МБ.
5. **Проверка перед сдачей** — обязательно, по правилам из `CLAUDE.md`: DNSMOS, повторное распознавание, клиппинг, громкость, кадры, синхрон субтитров, паузы. Ты не слышишь звук — поэтому опирайся на цифры и напиши, какие проверки прошли.
6. Закоммить результат в `projects/testimonio/out/` (`testimonio.mp4`, `testimonio-phone.mp4`, образцы звука) и запушь.
